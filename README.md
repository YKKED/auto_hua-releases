## 功能

- 月灵之森六关自动识别捕鱼、鱼群追踪和自动选炮，优化第2–6关目标识别。
- 普通炮1–7级；激光至少覆盖一只本关最高档奖励目标时才发射。
- 固定使用激进模式，隐藏模式选择和运行中的模式显示；保留资源底线和炮数、时长、净消耗上限。
- 任务队列、默认计划、已有常用计划和自动更新；「任务计划」及「日常 / 周常」入口已隐藏，数据保留。
- 捕鱼连续错误5次后异常中止，自动重启一次并继续累计运行上限；再次连续错误5次则停止，任务返回队列。手动停止不重启。

## 使用教程

1. 安装 MuMu 安卓12，将分辨率设为 **1280×720**。电脑需 Windows 10/11 64位。
2. 启动安卓《小花仙》，手动进入月灵之森要捕鱼的关卡，程序支持六关自动识别。
3. 下载便携包并解压，运行 `auto_hua.exe`。
4. 在「设备设置」填写实例名，点击「保存设置」和「检查实例」；留空默认选第一个实例。路径识别失败时填写 `MuMuManager.exe` 路径。
5. 在「捕鱼设置」设置炮级、保留资源和运行上限，点击「保存设置」；勾选「自动选炮」可自动选炮。程序固定使用激进模式，无需选择模式。
6. 程序打开后调度器保持停止。在游戏中进入对应关卡后，到「总览」点击调度器「启动」：空队列会添加一个「自动捕鱼」任务，按「捕鱼设置」的运行上限执行；已有队列按原计划运行，未来定时任务仍等待原时间。点击「停止」停止执行并保留队列。

「任务计划」及「日常 / 周常」入口已隐藏，默认计划、已有常用计划及队列数据保留；已加入队列的任务仍可运行。当前界面不提供编辑计划或应用常用计划的入口，空队列可通过「总览」的「启动」开始自动捕鱼。

原「六关捕鱼开发验证」任务现显示为「自动捕鱼」。已有默认计划仍可能显示「月灵之森自动捕鱼」，两者均支持六关自动识别；任务标识保持不变，旧队列和运行记录无需重建。

更新：在「更新」页面点击「检查更新」和「下载」，也可开启「自动下载更新」。下载完成后询问是否重启；「稍后重启」保持程序和任务运行，「立即重启」保留队列并安装新版。稍后也可点击「更新」安装。新版首次启动显示更新内容；更新重启后，在「总览」点击调度器「启动」继续原队列。

更新成功后自动清理旧更新缓存，配置、任务队列和运行记录保留。

移动或更新程序时，保留旁边的 `data` 文件夹。

自动重启后再次异常停止时，排除异常，在「总览」点击调度器「启动」继续，任务无需重新添加。
