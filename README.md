# 小花仙脚本

面向安卓《小花仙》的免费开源自动化助手，支持挖土豆活动、月灵之森捕鱼和任务队列。

## 功能

- **挖土豆活动**：自动进入活动、识别土豆与石头并放钩，达到每日上限后停止，次日自动排队。
- **月灵之森捕鱼**：支持六个关卡、关卡选择与自动识别，提供鱼群追踪、自动选炮和运行上限设置。
- **任务队列**：按勾选安排任务，优先完成活动；设置修改后自动保存并即时生效。
- **画面与更新**：查看游戏画面、任务进度和运行记录，在软件内下载并安装更新。

## 使用教程

### 1. 准备模拟器

电脑使用 **Windows 10 / 11 64 位系统**，安装 **MuMu 模拟器（Android 7.0 及以上）**。

将模拟器分辨率设为 **1280×720（横屏）**，重启模拟器。在模拟器中打开《小花仙》并登录，停留在游戏主页面。

### 2. 下载并打开软件

从以下任一平台下载 **1.2.0 正式版**：

- [GitHub](https://github.com/YKKED/auto_hua-releases/releases/tag/v1.2.0)
- [GitCode](https://gitcode.com/m0_66990166/auto_hua-releases/releases/v1.2.0)
- [Gitee 备用下载](https://gitee.com/YKKED/auto_hua-releases/releases/tag/v1.2.0)

GitHub、GitCode 下载 **auto_hua-portable.zip**。Gitee 下载以下三个文件，放在同一个文件夹并保留原文件名：

1. **auto_hua-1.2.0.zip.001**
2. **auto_hua-1.2.0.zip.002**
3. **merge-download.cmd**

使用 Gitee 下载时，双击 **merge-download.cmd**，等待合并和校验成功，生成 **auto_hua-portable.zip**。

将压缩包完整解压，再双击文件夹内的 **auto_hua.exe**。不要直接在压缩包中运行。

### 3. 连接模拟器

打开软件左侧「设备设置」：

1. 只开了一个模拟器时，「MuMu 实例名称」可以留空；开了多个时，填写要使用的实例名称。
2. 点击「检查实例」。
3. 进入「总览」，确认监视器能显示游戏画面。

如果提示找不到模拟器，在「MuMu 管理程序路径」中填写模拟器安装目录内 **MuMuManager.exe** 的完整路径，再点击「检查实例」。

### 4. 选择任务

- **挖土豆**：打开「活动」，勾选「加入队列」。
- **捕鱼**：打开「捕鱼设置」，选择已解锁的「捕鱼关卡」，按需设置自动选炮、保留资源和运行上限，再勾选「加入队列」。标有「0 不限」的项目填 0 表示不限制该项。

设置修改后自动保存，运行中的任务也会应用新设置。两项都勾选时，先完成活动，再执行捕鱼。

### 5. 启动与停止

回到「总览」，点击调度器「启动」，软件会自动进入任务页面。

活动达到今日上限后进入「等待中」，北京时间次日 **00:00** 自动重新排队；保持软件和调度器运行即可。取消活动的「加入队列」后，不再每日排队。

点击调度器「停止」可停止所有任务，取消某项「加入队列」可停止该项任务。挖土豆过程中停止后，请等待本局自然结算。

### 6. 更新软件

打开「更新」，点击「检查更新」。发现新版本后点击「下载」，下载完成后选择「立即重启」安装；也可选择「稍后重启」，方便时再完成安装。
