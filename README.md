# 小花仙脚本

面向安卓《小花仙》的免费开源自动化助手，支持活动任务、恶德花园和月灵之森。

## 功能

- **活动任务**：选择活动，自动完成任务。
- **恶德花园**：刷取勇者金币和宝石，支持九张地图。
- **月灵之森**：支持六个捕鱼关卡，可设置关卡、自动选炮和运行上限。
- **任务队列**：按优先级执行任务，设置即时生效。
- **软件更新**：在软件内检查、下载并安装新版本。

## 使用教程

### 1. 准备模拟器

电脑使用 **Windows 10 / 11 64 位系统**，安装 **MuMu 模拟器（Android 7.0 及以上）**。

将模拟器分辨率设为 **1280×720（横屏）**，重启模拟器。在模拟器中打开《小花仙》并登录，停留在游戏主页面。

### 2. 下载并打开软件

从以下任一平台下载 **1.3.0 正式版**：

- [GitHub](https://github.com/YKKED/auto_hua-releases/releases/tag/v1.3.0)
- [GitCode](https://gitcode.com/m0_66990166/auto_hua-releases/releases/v1.3.0)
- [Gitee 备用下载](https://gitee.com/YKKED/auto_hua-releases/releases/tag/v1.3.0)

GitHub、GitCode 下载 **auto_hua-portable.zip**。Gitee 下载以下三个文件，放在同一个文件夹并保留原文件名：

1. **auto_hua-1.3.0.zip.001**
2. **auto_hua-1.3.0.zip.002**
3. **merge-download.cmd**

使用 Gitee 下载时，双击 **merge-download.cmd**，等待合并和校验成功，生成 **auto_hua-portable.zip**。

将压缩包完整解压，再双击文件夹内的 **auto_hua.exe**。不要直接在压缩包中运行。

### 3. 连接模拟器

打开软件左侧「设备设置」：

1. 只开了一个模拟器时，「MuMu 实例名称」可以留空；开了多个时，填写要使用的实例名称。
2. 点击「检查实例」。
3. 进入「总览」，确认监视器能显示游戏画面。

如果提示找不到模拟器，在「MuMu 管理程序路径」中填写模拟器安装目录内 **MuMuManager.exe** 的完整路径，再点击「检查实例」。

### 4. 选择任务

- **活动**：打开「活动」，选择活动，再勾选「加入队列」。
- **恶德花园**：先在游戏中转职为「倒吊之人」，解锁下表中的目标普通关卡。在软件「恶德花园」中勾选「刷勇者金币」或「刷宝石」，再勾选「加入队列」。
- **月灵之森**：选择已解锁的「捕鱼关卡」，按需设置自动选炮、保留资源和运行上限，再勾选「加入队列」。标有「0 不限」的项目填 0 表示不限制该项。

恶德花园只刷金币时，可自行选择地图；勾选刷宝石后，按地图顺序刷取。达到所选每日目标后等待次日继续。普通用户与 VIP 均按游戏显示的上限执行。

| 地图 | 需解锁关卡 |
| --- | --- |
| 魔法森林 | 普通 7 |
| 烈焰沙漠 | 普通 9 |
| 冰岩洞穴 | 普通 11 |
| 恶德花园 | 普通 11 |
| 浪漫鹊桥 | 普通 11 |
| 星辰之夜 | 普通 11 |
| 云之彼端 | 普通 11 |
| 布偶之坟 | 普通 11 |
| 天狗之森 | 普通 11 |

设置自动保存并立即生效。任务优先级为：活动 → 恶德花园 → 月灵之森。

### 5. 启动与停止

回到「总览」，点击调度器「启动」，软件会自动进入任务页面。

点击调度器「停止」可停止所有任务；取消某项「加入队列」可停止该项任务。

### 6. 更新软件

打开「更新」，点击「检查更新」。发现新版本后点击「下载」，下载完成后选择「立即重启」安装；也可选择「稍后重启」，方便时再完成安装。
