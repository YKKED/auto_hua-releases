# 小花仙脚本

## 功能

- 月灵之森自动捕鱼、鱼群追踪和自动选炮。
- 普通炮1–7级与激光，支持保守、均衡、激进三种模式。
- 目标资源、运行时长、定时和长期任务。
- 任务队列、常用计划、自动更新。
- 操作连续失败5次后停止，任务返回队列。

## 使用教程

1. 安装 MuMu 安卓12，将分辨率设为 **1280×720**。电脑需 Windows 10/11 64位。
2. 启动安卓《小花仙》，进入月灵之森第1关「波月湖畔」。
3. 下载便携包并解压，运行 `auto_hua.exe`。
4. 在「设备设置」填写实例名，保存并检查连接；留空默认选第一个实例。路径识别失败时选择 `MuMuManager.exe`。
5. 在「捕鱼设置」选择模式与炮级并保存；勾选「自动选炮」可自动切换炮级。
6. 在「总览」停止调度器，再到「任务」设置目标资源、时长或时间，点击「添加计划」。勾选「长期」则持续运行。
7. 回到「总览」点击「启动」开始执行，点击「停止」停止执行并保留队列。

常用计划：填写名称并保存；选择计划后点击「应用」，会替换现有任务列表。

更新：在「更新」页面检查更新，也可开启自动下载与任务结束后安装。完成后选择「稍后重启」或「立即重启」；新版首次启动会显示更新内容。

移动或更新程序时，保留旁边的 `data` 文件夹。

故障停止后，排除异常并点击「启动」继续，任务无需重新添加。
