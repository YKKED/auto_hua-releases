# auto_hua releases

Portable Windows application for MuMu Android 12.

Download the latest auto_hua-portable.zip from Releases and extract it. Run auto_hua.exe. Preserve an existing data directory when replacing application files.

Updates are checked and downloaded automatically. Signed manifests and SHA256 verify update files. Installation waits until the active task ends, retains user data, verifies the updated application, and restores the old program if verification fails.

Requirements: Windows 10/11 x64, MuMu Android 12, the Android game, and a 1280x720 emulator display. Python, OCR models, ADB and required runtime libraries are bundled.

Release files: auto_hua-portable.zip, latest.json, latest.sig.
The repository contains release materials; signing private keys and user data are never published.
