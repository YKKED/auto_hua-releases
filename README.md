# 小花仙脚本

小花仙脚本是一款用于安卓《小花仙》月灵之森的自动捕鱼助手，支持六关识别、鱼群追踪和自动选炮。

## 功能

- 月灵之森六个关卡自动识别与自动捕鱼。
- 鱼群识别、持续追踪与自动选炮。
- 游戏画面预览、运行状态与日志查看。
- 软件内检查、下载和安装更新。

## 使用教程

### 1. 准备电脑和模拟器

电脑使用 **Windows 10 / 11 64 位系统**，安装 **MuMu 模拟器（Android 7.0 及以上）**。

在模拟器设置中，将分辨率设为 **1280×720（横屏）**。修改后重启模拟器，让设置生效。

### 2. 进入游戏捕鱼画面

在模拟器中打开《小花仙》并登录，手动进入「月灵之森」，选择已经解锁的捕鱼关卡。

等到画面中出现鱼群和炮台后，保持在这个界面。

### 3. 下载并打开助手

在本仓库的「发行版 / Releases」页面下载 **auto_hua-portable.zip**，将压缩包完整解压到一个文件夹，再双击其中的 **auto_hua.exe**。

请从解压后的文件夹运行程序，不要直接在压缩包内打开。

### 4. 连接模拟器

打开助手左侧的「设备设置」：

1. 只开了一个模拟器时，「MuMu 实例名称」可以留空；开了多个时，填写要使用的实例名称。
2. 点击「保存设置」，再点击「检查实例」。
3. 检查成功后，进入「总览」，确认监视器能显示当前游戏画面。

如果程序提示找不到模拟器，在「MuMu 管理程序路径」中填写模拟器安装目录内 **MuMuManager.exe** 的完整路径，再保存并检查一次。

### 5. 保存捕鱼设置

打开「捕鱼设置」，首次使用可先保留默认参数：

1. 需要助手自动选择炮级时，勾选「自动选炮」；需要固定炮级时，取消勾选并设置「炮级（1–7）」。
2. 按需设置「保留资源」和炮数、时长、净消耗上限。标有「0 不限」的项目，填写 0 表示不限制该项。
3. 点击「保存设置」。

### 6. 开始和结束捕鱼

确认模拟器仍停留在捕鱼画面，回到助手的「总览」，找到右侧「调度器」，点击「启动」。

开始后，可以在监视器和运行日志中查看捕鱼情况。需要结束时，在同一位置点击「停止」。

### 7. 更新软件

打开「更新」页面，点击「检查更新」。发现新版本后，点击「下载」。

下载完成后，选择「立即重启」安装更新；暂时不方便重启时，选择「稍后重启」，方便时再回到「更新」页面完成安装。
